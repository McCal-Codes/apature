Ferret Motion Lab

Every parameter is a damped spring. Press an event mid-motion and the ferret redirects instead of snapping. Each event is one-shot: it settles back to rest on its own within five seconds, and nothing loops.

Rules this prototype enforces
  • Motion starts only from an event; there is no idle loop, not even a blink.
  • Every event returns to rest by itself; the bar shows the five-second budget.
  • A new event redirects the springs mid-flight; nothing waits for a clip to end.
  • Squash and stretch preserve volume and stay under 12 %.
  • With Reduce Motion the same states appear by cross-fade in 120 ms.

Defaults follow Apple's spring guidance: response 0.4–0.5 s, bounce 0.15–0.2 for playful UI; the tail runs on a second spring with the same parameters but a lag, which is what reads as "fluid".
