# Mascot concepts — "a cute little camera guy"

Three proposals (2026-10-14), none adopted yet; the app icon stays the
2×2 contact-sheet mark until the owner picks. Palette is the Apature Dark
set (charcoal #26262B / #1B1B1F, lavender #BDB4EE / #E2DDFB, off-white
#ECEBF3) with one warm blush pink so the character reads as friendly on
either appearance.

| | file | idea | best for |
|---|---|---|---|
| A | `a-lensy.svg` | the lens is the eye; stubby arms and legs; prism cap | empty states, About window, stickers |
| B | `b-snap.svg` | two eyes above a lens "belly", waving arm, dark body | splash / onboarding, README hero, loading states |
| C | `c-mark.svg` | camera glyph with a tiny face inside the lens, no limbs | app icon, menu-bar/tab icon: survives 16 px |

`mascot-sheet.png` shows all three at 512 px and at 64/32/16 px.

Where a mascot would appear in the app (proposal): the empty sheet
("Drop a folder…"), the About window, the ingest "card mounted" toast,
and the README. Not in the toolbar or on every frame: it is a greeting,
not chrome. A and B can share C as their icon form, so one character can
have a full-body and an icon version (Finder and Slack do the same).

Recommendation: **C for the icon** (legible at every size, still a
camera), **B as the full-body character** for the README, About and
onboarding; A kept as an alternate if B feels too busy.
