# Animal mascot options (2026-10-14)

The owner asked for "more of an animal" than the camera-with-a-face. Six
drafts in the same palette, each with a camera trait built into the body
so the character is still about photography, not a pet holding a prop.

| | file | character | the camera in it | why it fits Apature |
|---|---|---|---|---|
| A | `owl.svg` | **Lumen** the owl | binocular lens eyes | sees in the dark (darkroom), the editor's eye, reads at 16 px |
| B | `raccoon.svg` | **Bandit** the raccoon | eye mask is the viewfinder band; holds a camera | night worker with hands: culling, captioning, carrying cards |
| C | `shutterbug.svg` | the **Shutterbug** | the shell is an aperture iris | the oldest nickname for a photographer; the iris is pure Apature |
| D | `cat.svg` | **Kit** the cat | lens-ring eyes with slit pupils, tail curls like a strap | quick, independent, judges everything |
| E | `otter.svg` | **Otto** the otter | floats and holds the camera on its belly | calm under pressure; otters hold their favourite things |
| F | `chameleon.svg` | **Cham** | one eye is a lens turret | changes with the theme (Dark / Light), eyes that scan |

`sheet.png` shows all six at 512 px with 64/32/16 px previews.

Recommendation: **C Shutterbug** for a brand with a story (the pun, the
iris as logo mark) or **A Lumen** for the most legible icon. B is the most
"character" and would make the richest pose library. Whichever is chosen,
it replaces Snap in the brand kit using the same parts approach, and the
old camera concepts stay in `../` for the record.
