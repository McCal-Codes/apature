# Lumen: six cute treatments (2026-10-14)

The owner chose **A Lumen** (the owl with binocular lens eyes) and asked
for other cute versions, pointing at Minecraft's new mob **Blub**: a
palm-sized, blocky, softly glowing jelly with tall ears and one-pixel
eyes, revealed at Minecraft LIVE in September 2026. Blub's cuteness comes
from four things: tiny scale, very few features, a soft inner glow, and
a slight jiggle. These six keep Lumen's parts (tufts, lens eyes, gold
beak and feet, lavender wings, blush) and change the rendering language.

| | file | treatment | where it would live |
|---|---|---|---|
| A | `voxel.svg` | Blub's language: blocks, translucent lavender glow, one-pixel eyes on lens blocks | easter-egg empty state, a "jiggle" idle animation, stickers |
| B | `blob.svg` | translucent jelly, no limbs, inner glow, dot eyes | loading states, the smallest friendly form, app-icon alternate |
| C | `chibi.svg` | big head, tiny body, enormous lens eyes | README hero, About window |
| D | `pixel.svg` | a true 16×16 sprite | favicon, status-bar toasts, menu-bar extra |
| E | `sticker.svg` | thick white outline and soft shadow | Discord/iMessage stickers, release notes |
| F | `plush.svg` | soft shading and a stitched seam | merch mockups, splash |

Recommendation: keep the flat vector Lumen (`../animals/owl.svg`) as the
canonical mascot and app icon; adopt **B blob** for loading and idle
moments (it is the Blub idea translated: small, glowing, jiggling), **D
pixel** for every place under 24 px, and **C chibi** for the README.
Voxel is a fun one-off, not a system.
