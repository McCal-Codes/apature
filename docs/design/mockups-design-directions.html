Apature Dark

Deep charcoal surfaces with no hue near the photographs, compact controls, 6-across sheet, subtle lavender used only for focus, selection and active filters.

Spacing

  • Toolbar 48 pt, status 28 pt, 16 pt side padding
  • Sheet padding 12, cell gap 12, 4 pt between image, name and marks
  • Sidebar rows 26 pt tall with 8 pt gutters; inspector sections 16 pt apart

Density

  • Filenames and marks legible at 6 across
  • Filter chips show what is hiding the other 77 photos
  • Preview at the top of the inspector so the focused frame is always visible while culling

Apature Light

Soft off-white panels, a neutral light-grey photo ground, restrained system blue for focus and selection, open spacing with the same controls in the same places.

Spacing

  • Same toolbar, status and sidebar metrics as Dark
  • Sheet padding 16, cell gap 16, 5 across by default
  • Class chips carry the full name where the extra width allows

Shared system

  • Switches with System Settings → Appearance, or per window
  • Every colour is a token; nothing is restyled by hand
  • Star colour darkens in Light to keep 4.5:1 on off-white

Caption workspace

Photograph beside the fields, filmstrip below, assignment headline in the editorial serif. Code replacements expand inline and stay tinted until the field blurs so a wrong code is caught.

Spacing

  • Fields column 320 pt with 16 pt padding and 12 pt between fields
  • Field boxes 30 pt minimum, caption 84 pt, 7×9 pt inner padding
  • Photo pane keeps 24 pt around the image at any window size

Keyboard

  • ⌘⏎ saves and advances; Tab moves field to field; Esc leaves the field
  • No culling shortcut fires while a field has focus
